# 핀터레스트 준비 절차 (사람이 해야 하는 일)

코드는 다 돌아가는 상태다. 아래 4가지가 끝나야 핀이 실제로 올라가고, 성과가 측정된다.
**순서가 중요하다** — 소유권 확인 전에 핀을 올리면 출처가 붙지 않아 노출이 낮게 시작한다.

## 1. 비즈니스 계정 만들기 (필수, 5분)

- https://www.pinterest.com/business/create/ — 픽담 전용으로 새로 만든다(개인 계정과 분리).
- 프로필명 `픽담`, 웹사이트 `https://pickdam.com`, 소개는 사이트 태그라인과 같게.
- 원더랜드용 계정은 **지금 만들지 않는다.** 1단계는 픽담 하나다(사용자 확정 2026-09-08).

## 2. 사이트 소유권 확인 (Claim website) — **가장 중요**

설정 → **Claim** → `pickdam.com` 입력 → HTML 태그 방식 선택.

- 워드프레스 픽담에는 **Rank Math가 이미 설치돼 있다**(2026-09-08 완료).
  Rank Math → 일반 설정 → **Webmaster Tools** → `Pinterest Verification ID` 칸에
  핀터레스트가 준 `content` 값을 붙여넣고 저장하면 끝난다(테마 파일을 건드리지 않는다).
- 저장 후 핀터레스트로 돌아와 **확인(Verify)** 을 누른다.
- 확인되면 이 사이트로 향하는 모든 핀에 픽담 출처가 붙고, 애널리틱스에서 사이트별 통계가 열린다.

## 3. 보드 만들기

- 보드 이름은 `markto.json`의 `sites[].board` 값과 **글자 그대로 같아야** API가 찾는다.
  현재 값: **`픽담 살까 말까`**
- 보드 설명에 핀터레스트 검색에 걸릴 말을 넣는다(예: 가전 살까 말까, 주방용품 고르는 법, 자취 살림).

## 4. API 앱 등록 (승인까지 시간이 걸리므로 지금 넣어두면 좋다)

- https://developers.pinterest.com/apps/ → Create app
- 앱 설명에 "자사 블로그(pickdam.com)의 발행 글을 자사 보드에 게시" 라고 적는다.
- 처음에는 **trial**(본인 계정만 가능)로 시작하고, 검수 후 **standard**로 올라간다.
- 필요한 스코프: `boards:read`, `pins:write`
- 토큰이 나오면 GitHub Secrets에 `PINTEREST_TOKEN`을 넣고,
  `markto.json`의 `publish.mode`를 `"telegram"` → `"pinterest"`로 바꾸면 자동 게시로 전환된다.

## 승인 전 운영 방식 (지금)

매일 10:20 KST에 워크플로가 핀 이미지와 문구를 **텔레그램으로 보낸다.**
폰에서 이미지를 저장하고, 캡션의 제목·설명·링크를 그대로 붙여 핀터레스트에 올리면 된다.
캐스토가 같은 방식(텔레그램 → 폰 업로드)으로 이미 굴러가고 있는 검증된 경로다.

## 성과 확인

핀 링크에는 `utm_source=pinterest&utm_medium=social&utm_campaign=markto`가 자동으로 붙는다.
GA4 또는 GSC에서 이 소스로 들어온 세션이 곧 마크토의 성과다. 팔로워 수는 보지 않는다.
