## 1. 비즈니스 계정 만들기

**픽담 전용으로 새로 만든다.** 개인 계정과 섞지 않는다 — 브랜드 계정과 개인 취향 핀이 한 프로필에 섞이면
핀터레스트가 계정 주제를 못 잡는다.

방법은 세 가지인데 **"기존 개인 계정에 비즈니스 계정을 추가로 연결"** 이 가장 편하다.
로그인을 따로 하지 않고 프로필 메뉴에서 전환할 수 있다.

- 새로 만들기: https://www.pinterest.com/business/create/
- 이미 핀터레스트 개인 계정이 있으면: 오른쪽 위 프로필 → **계정 추가**(Add account) → **비즈니스** 선택

입력값 (픽담 기준으로 그대로 쓰세요)

| 항목 | 값 |
|---|---|
| 프로필 이름 | `픽담` |
| 웹사이트 | `https://pickdam.com` |
| 사업 유형 | 블로거 / 퍼블리셔 (Creator·Publisher 계열) |
| 국가·언어 | 대한민국 / 한국어 |
| 광고 실행 여부 | **아니요** (물어보면 건너뛴다. 지금은 무료 유입만 본다) |

> 이메일: 연결형 비즈니스 계정은 같은 이메일로도 만들 수 있다. 다만 나중에 원더랜드용 계정까지 만들 거라면
> 계정별로 구분되는 이메일을 쓰는 편이 관리가 쉽다(`one2k87+pickdam@gmail.com` 처럼 `+` 별칭 사용 가능).

**비즈니스 계정이어야 되는 것**: 애널리틱스(핀 클릭·노출), 사이트 소유권 확인, 리치핀, 트렌드.
개인 계정으로는 이 중 어느 것도 못 한다.

## 2. 프로필 채우기 — 건너뛰지 말 것

빈 프로필은 핀터레스트가 "신뢰할 수 없는 신규"로 취급해 초기 노출을 거의 주지 않는다.

- **프로필 사진**: 픽담 로고를 쓴다 → `Picto/brand/pickdam-logo-512.png` (정사각 512, 브랜드 그린 바탕)
  > 이 항목만은 **사람이 직접** 올려야 한다. 핀터레스트의 [변경] 버튼은 누르는 순간 OS 파일 선택창을 띄우고,
  > 그 창은 브라우저 자동화가 볼 수도 조작할 수도 없다(그래서 자동화가 여기서 멈춘다).
- **소개(About)**: 검색될 말로 쓴다. 예:
  > 사기 전에 확인하는 곳. 가전·주방·생활용품을 살까 말까 기준으로 정리합니다.
- **웹사이트**: `https://pickdam.com` (3번을 하면 여기에 체크 표시가 붙는다)
- **사용자 이름(@)**: `pickdam` 이 비어 있으면 잡아둔다. 핀 출처 표기에 쓰인다.

## 3. 사이트 소유권 확인 (Claim website) — **가장 중요**

이걸 해야 ①모든 핀에 픽담 출처가 붙고 ②애널리틱스에서 사이트별 통계가 열리고 ③리치핀이 가능해진다.

### 3-1. 핀터레스트에서 코드 받기 (2026-09-09 실측 화면 기준)

**설정 → Pinterest에 연결 → 「웹사이트」 줄의 [소유권 표시] 버튼**
→ 열린 창에 주소 입력 → **HTML 태그 추가** 선택 → 보이는 `<meta name="p:domain_verify" ...>` 복사

> ⚠️ **주소가 `http://`로 미리 채워져 나온다.** 반드시 `https://pickdam.com`으로 고칠 것
> (픽담은 9/8에 siteurl을 https로 바로잡았다. http로 claim하면 정본과 어긋난다). 실측으로 걸린 함정.
> ⚠️ **별도의 "확인/Verify" 버튼은 없다.** 태그를 미리 심어두고 창 아래 [웹사이트 소유권 표시]를 누르면
> 그 자리에서 "연결됨 · 인증되었습니다"가 뜬다(대기 없음). 옛 안내의 "확인을 누른다"는 단계는 사라졌다.

> 방법은 HTML 태그 / HTML 파일 업로드 / DNS TXT 세 가지다. **HTML 태그가 가장 쉽다** —
> 픽담엔 Rank Math가 있어서 테마 파일을 건드릴 필요가 없다. DNS TXT는 반영에 최대 72시간이 걸린다.

### 3-2. 픽담(워드프레스)에 넣기

**Rank Math SEO → 일반 설정(General Settings) → 웹마스터 도구(Webmaster Tools)**
→ **Pinterest Verification ID** 칸에 복사한 값을 붙여넣고 **변경 저장**

- 태그 전체(`<meta name="p:domain_verify" content="abc123...">`)를 붙여도 되고 `content` 값만 붙여도 된다.
  Rank Math가 둘 다 받아 `<head>`에 넣어준다.
- 저장 후 **WP 슈퍼 캐시를 퍼지**한다. 캐시된 옛 `<head>`가 나가면 핀터레스트가 태그를 못 찾는다.

### 3-3. 소유권 표시 누르기

같은 창에서 **[웹사이트 소유권 표시]** 클릭 → 즉시 "연결됨 · 인증되었습니다".
프로필 수정 화면의 웹사이트 칸에도 체크 표시가 붙는다(2026-09-09 실측).

### 걸리는 지점 (미리 알아두면 안 헤맨다)

- **한 사이트는 한 계정만 확인할 수 있다.** 나중에 원더랜드용 계정을 따로 만들 때 픽담을 거기 붙이면 안 된다.
- **www / http 주소로 넣지 말 것.** 픽담은 `https://pickdam.com`이 정본이다(9/8에 siteurl을 https로 고쳤다).
- 실패하면 로그아웃 상태로 `https://pickdam.com` 소스를 열어 `p:domain_verify`가 `<head>`에 있는지 본다.
  없으면 캐시이거나 Rank Math 저장이 안 된 것이다.
- **NinjaFirewall 주의**: 9/8에 'Block attempts to modify important WordPress settings' 때문에
  설정 저장이 되돌아간 적이 있다. Rank Math 저장이 반영되지 않으면 이걸 먼저 의심한다.

## 4. 보드 만들기

**보드 이름은 `markto.json`의 `sites[].board` 값과 글자 그대로 같아야** 나중에 API가 찾는다.

- 현재 설정값: **`픽담 살까 말까`**
- 보드 설명에 검색될 말을 넣는다. 예:
  > 가전·주방·생활용품을 살까 말까 기준으로 정리합니다. 가격보다 쓸모를 먼저 봅니다.
- 보드는 하나로 시작한다. 글이 쌓이면 주제별(주방 / 가전 / 자취살림)로 쪼갠다.
  처음부터 여러 보드를 만들어 두면 각 보드가 텅 비어 있어 오히려 약해 보인다.

## 5. GitHub 시크릿 3종 — 이걸 넣으면 첫 핀이 온다

`https://github.com/one2k87/Markto/settings/secrets/actions` → **New repository secret**

| 이름 | 값 |
|---|---|
| `LLM_API_KEY` | Gemini 키 — **캐스토와 같은 값** |
| `TELEGRAM_TOKEN` | 캐스토와 같은 값 |
| `TELEGRAM_CHAT_ID` | 캐스토와 같은 값 |

넣으면 매일 **10:20 KST**에 핀 이미지 + 문구가 텔레그램으로 온다.
당장 확인하고 싶으면 Actions 탭 → `핀 자동 제작` → **Run workflow** 로 즉시 실행할 수 있다.

### 승인 전 운영 방식 (지금 이게 정상 운영이다)

1. 텔레그램으로 온 이미지를 폰에 저장
2. 핀터레스트 앱 → 만들기 → 이미지 선택
3. 캡션에 붙어온 **제목 / 설명 / 링크**를 그대로 복사해 넣기
4. 보드는 `픽담 살까 말까`

하루 2~3건이면 충분하다. 같은 글을 여러 번 올리는 것이 스팸 판정 1순위라 코드가 상한을 막아뒀다.

## 6. API 앱 등록 (자동 게시용 — 급하지 않다)

https://developers.pinterest.com/apps/ → **Create app**

- 앱 설명: "자사 블로그(pickdam.com)의 발행 글을 자사 보드에 게시"
- 필요한 스코프: `boards:read`, `pins:write`
- 개인정보처리방침 URL을 요구하므로 픽담의 `/개인정보처리방침/` 주소를 넣는다

### ⚠️ 여기서 반드시 알아야 하는 것 — trial로는 자동 게시를 켜면 안 된다

공식 문서 그대로다: **trial 등급으로 API가 만든 핀·보드는 Sandbox 취급이라 "만든 사람에게만 보인다".**
즉 trial에서 자동 게시를 켜면 **아무도 볼 수 없는 핀을 만들면서 큐만 소진한다**
(마크토가 그 글을 '핀 완료'로 기록해 30일간 다시 집지 않는다). 유입은 0이다.

그래서 `markto.json`에 `publish.access_tier`를 두고, **standard가 아니면 코드가 게시를 거부한다.**
승인 전까지는 5번의 텔레그램 수동 게시가 유일한 정상 경로다.

### standard 승인 신청

My apps → 앱 카드의 **Upgrade** → 정보 확인 → **데모 영상 업로드** → 제출

- **거절 사유 1위는 영상에 OAuth 인증 흐름이 없는 것.** 로그인 화면부터 권한 승인, 그 토큰으로
  핀이 올라가는 장면까지 한 번에 찍어야 한다.
- 아이디·비밀번호를 직접 받는 방식으로 보이면 거절된다.
- 승인 결과는 메일로 온다.

### 승인된 뒤 할 일 (5분)

1. GitHub 시크릿에 `PINTEREST_TOKEN` 추가 (필요하면 `PINTEREST_BOARD_ID_PICKDAM`도)
2. `markto.json`에서 두 값만 바꾼다: `publish.mode` → `"pinterest"`, `publish.access_tier` → `"standard"`
3. 1건으로 시험 실행해 `data/pins.json`에 `pin_id`가 남는지 확인

## 7. 리치핀 (소유권 확인 후 자동으로 따라온다)

리치핀은 핀에 글 제목·설명·출처를 붙여 보여주는 형식이다. 픽담은 **Rank Math가 이미
Open Graph와 JSON-LD를 넣고 있어**(9/8 완료) 따로 마크업 작업이 없다.
소유권 확인을 마친 뒤 핀터레스트 개발자 사이트의 리치핀 검사기에서 픽담 글 주소 하나를 넣어보면
메타데이터가 제대로 읽히는지 확인할 수 있다. 안 읽히면 대개 캐시이거나 대표 이미지가 없는 글이다.

## 8. 성과 확인 — 팔로워 수를 보지 않는다

모든 핀 링크에 마크토가 자동으로 붙인다:

```
utm_source=pinterest&utm_medium=social&utm_campaign=markto
```

- **핀터레스트 애널리틱스**: 핀 클릭 수 (노출·저장보다 이걸 본다)
- **GA4 / GSC**: 이 UTM으로 들어온 세션 = 마크토의 성과

핀 하나의 수명은 몇 달~몇 년이다. 2주 만에 판단하지 말고 **8주 누적 클릭**으로 본다.
